# 🎬 Movie Data Analysis using Python

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA) on a movie dataset using Python**. The analysis focuses on understanding movie ratings, genres, votes, gross income, actors, directors, duration, and release-year trends.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* YData Profiling
* Google Colab

## 📂 Files in this Repository

### `Movies_Project.ipynb`

Google Colab notebook containing the complete data cleaning, exploratory analysis, statistical analysis, and visualizations.

### `movies.csv`

The movie dataset used for the analysis.

### `README.md`

Documentation and overview of the project.

## 🔍 Analysis Performed

* Data loading and inspection
* Data type analysis
* Data cleaning and preprocessing
* Missing-value analysis
* Movie rating analysis
* Movie release trends by year
* Genre analysis
* Director analysis
* Actor analysis
* Gross income analysis
* Vote and rating analysis
* Correlation analysis
* Data visualization

## 📊 Visualizations

The notebook includes:

* Movie ratings over the years
* Number of movies released per year
* Distribution of movie ratings
* Top 10 most frequent actors
* Year vs. rating
* Votes vs. rating
* Gross income and votes distributions
* Movie count by genre
* Correlation heatmap

## ▶️ How to Run

1. Download or clone this repository.
2. Open `Movies_Project.ipynb` in **Google Colab** or Jupyter Notebook.
3. Make sure `movies.csv` is in the same directory as the notebook.
4. Run the notebook cells sequentially.
